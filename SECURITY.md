# Security Policy

This repository defines cloud infrastructure (networking, AKS, container
registry, Key Vault, database). Misconfigurations here can expose real
resources.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/azure-wordpress-aks-infra/security/advisories/new>

Never include subscription IDs, tenant IDs, keys, state files or real IP
addresses in issues or pull requests; use redacted values.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` receives security fixes.
